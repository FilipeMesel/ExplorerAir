# IR Remote Component (`ir_remote`)

The `ir_remote` component provides low-level infrared (IR) transceiver capabilities for ESP-IDF (v5.x / v6.x) using the hardware Remote Control Peripheral (RMT). It allows capturing raw IR waveforms into microsecond timing arrays and transmitting them back to control devices such as Air Conditioners and TVs.

## Features

- **Raw Capture**: Captures pulse-width timings (marks and spaces in microseconds) directly from an IR receiver module.
- **Raw Transmit**: Replays custom or pre-recorded raw timing sequences using a 38kHz carrier wave.
- **Configurable Buffers**: Supports long IR commands (e.g., AC remotes requiring up to 700 raw values).
- **Non-blocking API**: Integrates safely into FreeRTOS tasks and event-driven architectures.

## Configuration & Usage Examples
1. Capture and Print IR Raw Code (Arduino-Style Reader)
This task listens for incoming IR signals from a remote control. When a complete signal is detected, it formats and prints a ready-to-copy uint16_t array directly to the console output.

```cpp
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
#include "ir_remote.h"

#define GPIO_IR_TX   18
#define GPIO_IR_RX   19

static const char *TAG = "IR_DUMPER";

void ir_capture_task(void *pvParameters) {
    ir_raw_command_t rx_cmd;

    ESP_LOGI(TAG, "Point your remote control at the receiver and press any button...");

    while (1) {
        // Poll for captured commands (non-blocking)
        if (ir_remote_read_last_command(&rx_cmd) == ESP_OK) {
            ESP_LOGI(TAG, "IR Signal Captured! Total Elements: %d", rx_cmd.length);

            // Print C-style array formatted for copy-pasting
            printf("\n// --- Captured IR Command ---\n");
            printf("const uint16_t ac_raw_code[%d] = {\n    ", rx_cmd.length);

            for (uint16_t i = 0; i < rx_cmd.length; i++) {
                printf("%u", rx_cmd.data[i]);
                if (i < rx_cmd.length - 1) {
                    printf(", ");
                }
                // Break line every 10 elements for clean formatting
                if ((i + 1) % 10 == 0) {
                    printf("\n    ");
                }
            }
            printf("\n};\n");
            printf("// ---------------------------\n\n");
        }

        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

void app_main(void) {
    // Initialize IR hardware channels
    ESP_ERROR_CHECK(ir_remote_init(GPIO_IR_TX, GPIO_IR_RX));

    // Start the dumper task
    xTaskCreate(ir_capture_task, "ir_capture_task", 4096, NULL, 5, NULL);
}
```

2. Transmit Hardcoded Raw Code (Arduino-Style Sender)
Paste the raw timing array generated by the capture example into the ir_raw_command_t structure to send the command to your target Air Conditioner.

```cpp
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
#include "ir_remote.h"

#define GPIO_IR_TX   18
#define GPIO_IR_RX   19

static const char *TAG = "IR_SENDER";

// Copied and pasted array captured from the remote control
const uint16_t ac_power_on_raw[] = {
    9000, 4500, 560, 560, 560, 1690, 560, 560, 560, 560,
    560, 1690, 560, 1690, 560, 560, 560, 1690, 560, 1690,
    560, 560, 560, 1690, 560, 560, 560, 560, 560, 560,
    560, 1690, 560, 1690, 560
};

void send_ac_command(void) {
    // Construct the command struct from the raw array
    ir_raw_command_t raw_cmd = {
        .length = sizeof(ac_power_on_raw) / sizeof(ac_power_on_raw[0])
    };
    
    // Copy timings into struct data buffer
    for (size_t i = 0; i < raw_cmd.length; i++) {
        raw_cmd.data[i] = ac_power_on_raw[i];
    }

    ESP_LOGI(TAG, "Transmitting AC Power ON signal via IR...");
    
    esp_err_t err = ir_remote_send_command(&raw_cmd);
    if (err == ESP_OK) {
        ESP_LOGI(TAG, "IR signal transmitted successfully!");
    } else {
        ESP_LOGE(TAG, "Failed to send IR signal: %s", esp_err_to_name(err));
    }
}

void app_main(void) {
    // Initialize IR hardware channels
    ESP_ERROR_CHECK(ir_remote_init(GPIO_IR_TX, GPIO_IR_RX));

    // Wait 2 seconds and trigger transmission
    vTaskDelay(pdMS_TO_TICKS(2000));
    send_ac_command();
}
```

## API Reference
`esp_err_t ir_remote_init(int gpio_tx, int gpio_rx)`
Configures and enables the RMT TX and RX channels, applies the 38kHz carrier wave modulation, and starts background listening.

`esp_err_t ir_remote_read_last_command(ir_raw_command_t *cmd_out)`
Non-blocking read function. Pulls the latest captured raw timings out of the FreeRTOS queue and rearms the receiver hardware.

`esp_err_t ir_remote_send_command(const ir_raw_command_t *cmd)`
Encodes the microsecond pulse lengths into RMT symbol words and drives the TX pin to emit the IR signal. Blocks until transmission completes.
